## 1. Регламент и критерии отбора

> [!IMPORTANT]
> **Главное правило:** Сохранить полностью работающий проект FurniCore ERP важнее, чем удалить файл.  
> Если есть малейшее сомнение в безопасности удаления — файл сохраняется, а в отчёте фиксируется обоснование.

### Категории анализа:
1. **Категория A (Безопасная очистка):** Неиспользуемые импорты в коде, временные байт-код кэши (`__pycache__`), не влияющие на бизнес-логику.
2. **Категория B (Оставить из соображений безопасности):** Служебные скрипты, бэкапы, конфигурации E2E, Nginx/Systemd, отслеживаемые скриншоты, TypeScript архивы.
3. **Категория C (Оставить, так как используются косвенно):** Все 63 HTML-шаблона, статические директории, медиа-файлы каталога мебели.

## 3. План действий на этапе очистки

1. **Точечная очистка неиспользуемых импортов** в 23 модулях `apps/` без изменения сигнатур функций и логики.
2. **Контроль компиляции**: запуск `python manage.py check` после каждого модуля.
3. **Регрессионное тестирование**: запуск полного набора тестов pytest (74 теста).
4. **Проверка ключевых интерфейсов** (дашборд, производство, склады, закупки, продажи, финансы, аналитика).
