# FurniCore ERP — Демонстрационные учётные записи (Demo Credentials)

> **ВНИМАНИЕ:** Данные учётные записи предназначены **исключительно для локальной демонстрации и тестирования** учебного проекта. Настоящие пароли, секретные ключи или персональные данные в проект не включаются.

---

## Единый пароль для всех демо-пользователей:
```
furnicore123
```

## Таблица ролей и демонстрационных аккаунтов

| Логин | Имя и фамилия | Роль в системе (`UserRole`) | Назначение для показа преподавателю |
|---|---|---|---|
| **`owner`** | Арман Сейткали | `OWNER` (Суперпользователь) | **Главный аккаунт для показа:** полный доступ ко всем разделам, дашборду, финансам, P&L, складам и настройкам. |
| **`admin_sys`** | Дмитрий Носов | `ADMIN` (Администратор) | Настройка системы, управление пользователями и правами. |
| **`accountant`** | Айгуль Мусина | `ACCOUNTANT` (Главный бухгалтер) | Финансовый дашборд, касса, банк Kaspi/Halyk, проведение оплат, печать PDF-квитанций, выгрузка P&L в Excel. |
| **`prod_manager`** | Сергей Быков | `PRODUCTION_MANAGER` (Нач. производства) | Запуск заказов в цех, расчёт потребности по BOM, канбан-доска, списание сырья. |
| **`wh_manager`** | Нурлан Ахметов | `WAREHOUSE_MANAGER` (Зав. складом) | Приёмка сырья на WH-1, отпуск в цех, инвентаризация, приёмка готовых изделий на WH-2, сканер штрихкодов. |
| **`sales_mgr`** | Алина Касымова | `SALES_MANAGER` (Менеджер продаж) | Оформление заказов клиентов, расчёт скидок, резервирование мебели на WH-2, оформление отгрузок. |
| **`worker1`** | Кайрат Джаксыбеков | `WORKER` (Столяр-мастер) | Сменные задания рабочих, фиксация этапов, отметка отработанных часов. |
| **`worker2`** | Иван Петренко | `WORKER` (Оператор ЧПУ) | Выполнение стадий раскроя и присадки, фиксация брака и отходов. |

## Быстрый вход
Для переключения ролей достаточно выполнить выход (кнопка в правом верхнем углу интерфейса) и войти под нужным логином с паролем `furnicore123`.
