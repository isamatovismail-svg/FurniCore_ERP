# FurniCore ERP — Инструкция по публичной демонстрации (Public Demo Setup)

**Версия документа:** 1.1.0  
**Назначение:** Безопасный запуск временного публичного HTTPS-доступа для преподавателя.  
**Стек:** Django 5.1, Gunicorn 27, PostgreSQL 16, Cloudflare Tunnel.

---

## 1. Архитектура безопасного публичного доступа

```
[ Браузер преподавателя (Внешний интернет) ]
                     │  (Защищённый HTTPS: https://*.trycloudflare.com)
                     ▼
          [ Cloudflare Edge CDN ]
                     │  (Зашифрованный туннель Cloudflare)
                     ▼
    [ Утилита cloudflared на вашем ПК ]
                     │  (Локальное проксирование: http://127.0.0.1:8000)
                     ▼
  [ Gunicorn WSGI (с поддержкой статики) ]
                     │
                     ▼
           [ FurniCore ERP ] ──► [ PostgreSQL 16 (127.0.0.1:5435) ]
```

### Гарантии безопасности:
1. **База данных PostgreSQL НЕ открывается в интернет** (доступна только локально на `127.0.0.1:5435`).
2. **Файл `.env`, секретные ключи и логи НЕ передаются** внешним клиентам.
3. **Панель Django Admin (`/admin/`) заблокирована** для преподавателя.
4. **CSRF и защита сессий активны** (токены валидируются через `CSRF_TRUSTED_ORIGINS = ['https://*.trycloudflare.com']`).

## 2. Пошаговая инструкция запуска

### Шаг 1: Создание отдельной учётной записи преподавателя
Никогда не передавайте преподавателю логин и пароль от аккаунта `owner` (суперпользователь).  
Выполните локальную команду:

```bash
cd "/home/linux/PycharmProjects/FurniCore ERP"
.venv/bin/python manage.py setup_teacher_account --interactive
```
- Система запросит пароль и подтверждение.
- Учётная запись `teacher` создаётся с ролью `OWNER` (полный функциональный просмотр ERP), но с `is_staff=False` и `is_superuser=False` (доступ к `/admin/` и системным настройкам физически закрыт).
- Пароль хранится в зашифрованном виде в базе PostgreSQL (PBKDF2/SHA256) и не сохраняется в Git.

### Шаг 2: Запуск WSGI-сервера Gunicorn
Для стабильной обработки запросов и безопасной отдачи статических файлов в демо-режиме запустите Gunicorn:

```bash
SERVE_STATIC=True .venv/bin/gunicorn config.wsgi:application --bind 127.0.0.1:8000 --workers 3
```
*(Параметр `SERVE_STATIC=True` активирует встроенный обработчик статики Django для корректного отображения стилей и скриптов без необходимости настройки Nginx).*

### Шаг 3: Запуск защищённого HTTPS-туннеля Cloudflare
В отдельной вкладке терминала запустите бесплатный туннель:

```bash
cloudflared tunnel --url http://127.0.0.1:8000
```
В выводе терминала появится строка:
```text
INF +--------------------------------------------------------------------------------------------+
INF |  Your quick Tunnel has been created! Visit it at (it may take some time to be reachable):  |
INF |  https://xxxx-xxxx-xxxx.trycloudflare.com                                                  |
INF +--------------------------------------------------------------------------------------------+
```

### Шаг 4: Передача ссылки преподавателю
Передайте преподавателю:
- **HTTPS-ссылку:** `https://xxxx-xxxx-xxxx.trycloudflare.com`
- **Логин:** `teacher`
- **Пароль:** пароль, заданный вами на Шаге 1.

## 3. Как остановить публичный доступ

Как только демонстрация завершена:
1. В терминале с `cloudflared` нажмите **Ctrl + C**.  
   *Туннель мгновенно уничтожается, публичный адрес перестаёт отвечать.*
2. В терминале с `gunicorn` нажмите **Ctrl + C**.  
   *Локальный сервер останавливается.*
3. (Опционально) Деактивируйте учётную запись преподавателя:
   ```bash
   .venv/bin/python manage.py shell -c "from apps.accounts.models import User; u = User.objects.get(username='teacher'); u.is_active = False; u.save(); print('Аккаунт teacher деактивирован')"
   ```

## 4. Ограничения временной демонстрационной ссылки

1. **Время жизни:** Ссылка активна только пока запущен процесс `cloudflared`. При перезапуске туннеля генерируется новый случайный адрес.
2. **Скорость:** Скорость загрузки зависит от вашего интернет-канала и географического маршрута до узла Cloudflare.
3. **AI Assistant:** В публичном туннеле работает в честном автономном режиме **`DEMO AI MODE`** (анализирует реальную базу PostgreSQL фабрики). Если в `.env` владельцем прописан `OPENAI_API_KEY`, ассистент использует внешнюю модель `gpt-4o-mini`.

---

## 5. Запрещённые действия при публичной демонстрации

❌ **Категорически запрещено:**
- Запускать туннель с включённым `DEBUG=True` на постоянной основе;
- Передавать учетные данные суперпользователя `owner` или `admin_sys`;
- Открывать входящие порты PostgreSQL (5432/5435) во внешний интернет;
- Отключать CSRF-защиту или использовать `ALLOWED_HOSTS = ['*']`;
- Загружать в демонстрационную систему реальные персональные данные (ИИН, сканы паспортов, номера банковских карт).
