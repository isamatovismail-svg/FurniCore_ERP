Инструкция по подключению OpenAI API

Для подключения внешней нейросетевой модели добавьте следующие переменные в локальный файл .env в корне проекта:

# OpenAI API Settings
OPENAI_API_KEY=sk-proj-your-actual-openai-api-key-here
OPENAI_MODEL=gpt-4o-mini

Рекомендуемые модели:

  • gpt-4o-mini (по умолчанию) — высокая скорость, минимальная стоимость токенов, отличный анализ ERP данных.
  • gpt-4o — для углублённых рассуждений и сложных аналитических сводок.

Архитектурные принципы безопасности AI

🔒 Изоляция API-ключа Ключ считывается только бэкендом на стороне сервера и никогда не передаётся в клиентский JavaScript, HTML-шаблоны или логи.
🛡️ Режим Read-Only AI-ассистент имеет исключительно доступ на чтение агрегированных данных. Он не может самостоятельно списывать сырьё, проводить платежи или менять статусы заказов.
👤 Конфиденциальность Пароли пользователей, персональные идентификаторы и конфиденциальные данные клиентов не передаются во внешний контекст промпта.
⚡ Отказоустойчивость В случае превышения лимитов или сбоев внешнего сервиса ассистент мгновенно переходит в локальный DEMO-режим без сбоя работы приложения.
